# CATSPACE V3 视觉拆解与验收

## V1 与 V2

V1 已接入 Three.js，但用基础圆环、细柱和统一金属材质表现建筑，镜头主要围绕核心旋转。首屏缺少清晰的地平面、楼层厚度、近景遮挡和有来源的环境反射。多面体的均匀亮边进一步削弱了数字生命与建筑的反差。

V2 用 CSS 透视椭圆和线条搭建空间。星空、楼板、地面、标签各用独立图层，缺少一致的消失关系、材质反射与尺度。虹彩渐变停在填色层面，围绕核心旋转无法读出内部结构。V3 重新构建这套视觉层级。

## 首轮可验收交付

- 桌面首屏有明确的左暗右亮、双层环廊、近景切边与低头地面反射。标题、按钮和空间节点在静止首帧可读。
- 探索支持五区聚焦、核心唤醒和小猫彩蛋。触屏可从底部导航到达全部区域。退出详情可用 Escape 或关闭按钮。
- 浏览模式可访问同样的内容。作品档案预置来自原站的五个已上线项目。切换模式时，同一区域在 URL 中保留。
- 无 WebGL 或减少动态效果时，保留建筑和核心构图、区域切换及操作反馈。提供可直接测试的静态切换参数。
- 生产资源使用相对路径。发布后核对页面、JS、CSS、图片与静态降级入口，并在实际浏览器检查主交互。

## 建筑资产边界

首轮建筑采用高细节底图与带深度的投影网格，支持有限镜头推进和视差。核心曲面、轨迹、波环、小猫和空间锚点在 WebGL 中实时绘制。当前镜头有意保留在概念图的取景范围内。

若扩展到能跨楼层移动的建筑，需要 Blender 模块化资产。可先以约 60 米的主厅直径与低位广角镜头做比例校验，再制作带倒角、楼板截面、玻璃护栏与阶梯的模块。金属用粗糙度贴图，地面高光用经过色彩校验的烘焙反射和分区灯光。导出 GLB 前按距离做 LOD，对贴图用 KTX2，对几何用 Meshopt。首屏继续保留图像底板，空间镜头用基准构图逐一校对。
