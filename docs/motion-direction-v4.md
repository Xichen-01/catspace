# CATSPACE V4 · The Awakening

V4 沿用 V3 的观测站与核心图像。V3 将建筑压在一块投影网上，核心反馈主要由一次脉冲驱动。切换区域时，详情先打开，镜头随后更新。V4 把这三个环节交给同一套带时间的场景与交互模型。

## 生命体状态

| 状态 | 进入条件 | 反馈 |
| --- | --- | --- |
| 休眠 | 初次进入，或长时间无人接近 | 膜片收拢，流光微弱 |
| 待机 | 开场约 1.3 秒，或完成恢复 | 展开到基准形态，缓慢呼吸 |
| 感知 | 指针接近、键盘聚焦或触屏按住 | 边缘偏冷，朝访客方向倾斜 |
| 好奇 | 感知持续约 0.74 秒 | 倾角和横向张力加大，膜片光流更强 |
| 苏醒 | 点击、轻触或键盘激活生命体 | 膜片舒展，向地面光环发出冲击波 |
| 共鸣 | 苏醒后再次发出信号 | 膜片偏紫，双道波环和地板反光回应 |
| 恢复 | 离开、共鸣结束或苏醒超时 | 收束为较暗的膜片，约 2.35 秒后回到待机或感知 |

## 动态节奏

- 按压响应约 150 毫秒，局部状态转场约 480 毫秒。核心能量从形态变化传到地面，声音只在访客主动开启后播放。
- 区域飞行约 1.26 秒，回大厅约 1.06 秒。镜头经过连续弧线，分层视差跟随各平面的深度改变。切换目标时从当下镜头位置起航。抵达后揭示内容约 430 毫秒，离开时旧内容约 235 毫秒淡出。
- 远景、星球、建筑、环廊和前景地台由同一幕景绘制在不同平面。遮罩让近处地台可以压在中景物体前。WebGL2 可用时，为核心加上实时虹彩曲面和薄环。
- 星空高光、灯带、地台扫描、微尘和膜片光流各有周期。主厅开启约 3 秒后，猫会沿平台巡游，随后停下观察。跟随猫时，它会从当下位置前往信号方向。
- 手机使用横滑观测窗、轻触或停留在核心上，以及抵达后的底部内容层。底部五区导航始终可以直接使用。
- 系统减少动态效果与 `?motion=off` 共用一条即时抵达路径。无 WebGL 的设备继续运行分层场景。`?still` 可以单独测试分层渲染。低内存设备使用较轻的渲染路径，窄屏只载入压缩后的观测站图。

## 实现和复核

`app-v4/src/motion.ts` 包含状态迁移、镜头和猫的坐标模型。`World.tsx` 同步场景、按钮、前景遮挡与环境图层。`station.ts` 渐进加载局部 3D。`sound.ts` 用 Web Audio 合成环境底音与事件提示音，浏览模式或标签页隐藏时淡出。

```sh
npm --prefix app-v4 ci
npm --prefix app-v4 test
npm --prefix app-v4 run dev
npm --prefix app-v4 run build:pages
```

V4 构建输出到 `v4/`。原来的 `app/` 和 `v3/` 仍提供 V3 源码与构建。
